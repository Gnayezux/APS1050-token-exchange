### To deploy the APS1050 Token Exchange locally and test its functionalities, make sure to deploy all 3 contracts (including 2 test token contracts)

0. Make sure you already have hardhat installed! To do so, simply `$ npm install` in the current directory, verify with `$ npx hardhat` to see if it can run.

1. First, start a local Ethereum chain with Hardhat. -> 
	```
	$ npx hardhat node
	```

2. It should output a bunch of accounts and private keys. Pick the first account (#0) and import its private key to your browser extension (MetaMask for instance) 
Open up Metamask and configure a new RPC server -> the local chain spawned by Hardhat `http://127.0.0.1:8545/`

3. Now deploy the contracts. -> 
	``` (Use a separate terminal window)
	$ npx hardhat ignition deploy ./ignition/Modules/Exchange.ts --network localhost
	$ npx hardhat ignition deploy ./ignition/Modules/TestToken1.ts --network localhost
	$ npx hardhat ignition deploy ./ignition/Modules/TestToken2.ts --network localhost
	```

4. Now notice the deployed address for the token exchange contract. After the above 3 contracts are deployed, Hardhat should show you something like this in the terminal: 
	```
	Deployed Addresses

	TokenExchange#TokenExchange - 0x5FbDB2315678afecb367f032d93F642f64180aa3
	MyToken#MyToken - 0xe7f1725E7734CE288F8367e1Bb143E90bb3F0512
	Mytoken2#Mytoken2 - 0x9fE46736679d2D9a65F0992F2272dE9f3c7fa6e0
	```

5. Paste the TokenExchange contract address to `exchangeConfig.js` file. (EXCHANGE_ADDRESS).
Change chainId on line 130 to `31337`

6. Go to the frontend directory and run 
	``` (Use a separate terminal window) 
	$ npm run dev
	```

7. Open up your browser and visit `http://localhost:5173/` 

8. Go to the "Token Balances" page and try to mint some test tokens of 2 kinds. Make sure your metamask is configured so that the TokenSwap UI can only access the local Hardhat chain! 

9. If mint is successful, you will see the balance being refreshed. You can also check the terminal window where you started the local chain to see events like `eth_sendRawTransaction` followed by the mint details. 

10. *** Now for the Create Order flow ***, navigate to the "Create Order" tab and fill all the required fields, then press "Publish On-Chain" 

11. It should try to ask you to sign transaction to approve spending caps in the token you want to trade for, then it will ask you to sign the order, and finally ask for a transaction to hit the Token Exchange contract and publish order on chain. 

12. You can verify from the terminal window where you spawned the local chain that the createOrder function is called for the Token Exchange contract. 

13. Now, navigate to the "Explore Orders" page to view the order you have just created. 

14. To test the "Cancel Order" functionality, you need to know the nonce of the create order event. This is usually easy by going to an explorer like EtherScan, but with local node spawned by HardHat, you need to use extra manual steps. 
	``` (Use a separate terminal window) 
	$ npx hardhat console --network localhost
	> const txHash = "0x2d8fdc854ce43900159cc2cfabfa7be67704700d480b7e4ce1c46c9c7b20afab"   // Replace with the actual create order Transaction hash (you can see it from the terminal window where you spawned the node)
	> const receipt = await ethers.provider.getTransactionReceipt(txHash)
	> const contract = await ethers.getContractAt("TokenExchange", "0x5FbDB2315678afecb367f032d93F642f64180aa3") // Replace with the actual address with the TokenExchange contract's address (see step 4) 
	> receipt.logs.map(log => contract.interface.parseLog(log));
	[
  		LogDescription {
    			fragment: EventFragment {
				......
		args: Result(9) [
			...... // Locate the nonce here! 
		]
	]
	```

15. Fill all the required fields at the "Cancel Order" page and make sure you are putting the correct nonce obtained using the step above. DO NOT include the trailing "n" symbol of the nonce. Double check order expiry and make sure it matches the one you used when creating the order.

16. After hitting the cancel order button, you can go back to the "Explore Orders" page and see that the cancelled order is no longer displayed there. 

17. To test the "Fill Order" functionality, go to "Explore Orders" page and click "Fill Order" button, follow the prompt to enter the amount you wish to buy.
	IMPORTANT: You must use 2 different wallet addresses in your local node in order to test this feature. Otherwise, the same wallet acts as buyer and seller, and you won't see the token balances changed after a successful transaction.
